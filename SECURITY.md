# Security Policy

SURGE is a static, client-side game with no backend, no accounts, and no data
collection. The only persisted data is your best score in `localStorage`, which
never leaves your browser.

## Reporting a vulnerability

If you find a security issue (for example, a way the page could be abused via a
crafted URL or a dependency-free XSS vector), please report it privately:

- Email **mack.ryanm@gmail.com**, or
- Open a [GitHub security advisory](https://github.com/kamoras/surge/security/advisories/new).

Please do not open a public issue for security reports. We will acknowledge your
report as soon as possible and keep you updated on the fix.
